The read-only audit in the planning conversation found the following. These are
not new results generated by the package-A preflight:

- `src/data/groups.py`: `reply_hash` uses the first 300 characters; combined hash
  requires simultaneous reply/title/subcategory matching, not OR components.
  The previously described 922 identical-reply tickets concern prefixes;
  normalized full-reply duplicates cover 238 tickets.

  queries leaves 174 dev feedback queries in the audited disjoint eval and does
  not restrict feedback candidates to history.
- `src/feedback/builder.py` / `retrieval/index.py`: string-ID versus integer-index
  exclusion mismatch; both old databases contain 878 self-pairs.
- `src/feedback/loader.py`: priors follow supplied rows; legacy `minus_query()`
  does not update priors. Correct filtering must precede both computations.
- Stored `Team->Name` is the resolving team (author clarification). Historical
  `label_auto` extraction uses `first_reply`; active intent routing reads its
  stored mapping. Neither is automatically a new-ticket input.
- `src/evaluation/ladder.py` and `retrieval/retrievers.py`: pool-cache checks do
  not fully identify history/configuration; CE keys used candidate row positions.

## Generated panel (package B2)

**3,513 new prompts**, model `openai/gpt-5.6-luna`, temperature 0.0, regime
`51fd9f4b37e900bb` (identical to the audited submitted run). Mean paired cosine
difference against baseline:

| Panel | Conditioned | Blind | Reply similarity |
|---|---:|---:|---:|
| random | +0.0105 | −0.0444 | +0.0143 |
| duplicate | +0.0149 | −0.0214 | +0.0081 |
| strict prefix | +0.0093 | +0.0008 | +0.0026 |

Direct protocol contrast: +0.0549 → +0.0363 → +0.0085 (strict p=.032). Blind harm
disappears under strict disjointness; the calibrated conditioned effect stays
small. On strict data the cosine interval excludes zero but the rank test is
marginal (p=.066) and ROUGE-L is not significant. Full intervals and the
zero-inflation explanation are in `GENERATED_RESULTS.md` and
`tables/generated_deltas.csv`.

One run logged a transient Windows `OSError` while writing `_interim.json`; the
ticket was already appended and all runs report `valid == total`. The interim
writer now catches filesystem errors so diagnostics can never drop a ticket.

Reproducibility note: the reply-similarity matrix is cached under `data/cache/`
and was rebuilt once during this work after a synthetic test accidentally wrote a
four-row matrix into the shared cache. A rerun with the rebuilt (canonical)
matrix reproduced every `delta_mean` to 1.5e-8 and produced zero significance
flips; Wilcoxon p-values shifted by at most 0.014 because float-level ties change
ranks. The panel summary now pins both reply-embedding files by SHA-256. The test
that caused this now uses a temporary cache directory.
