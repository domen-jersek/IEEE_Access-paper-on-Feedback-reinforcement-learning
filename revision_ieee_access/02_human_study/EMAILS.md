Dear Timothy,

thank you for agreeing to act as the second independent expert for our IEEE Access

**When:** Friday, 11:00–13:00 CET. Please start at 11:00 if possible. The app saves
after every item, so you can stop at 13:00 even if you have not finished; partial
coverage is useful and will be analysed on the items you completed.

**Where:** [URL, e.g. http://atena.ijs.si:5003/]

**Login:** rater ID `timothy`; access code [send separately / the shared code from
the earlier message]. The app runs on the institute server; nothing is installed
on your machine and no files need to be downloaded.

**What you will see.** The version you will use contains only the answer block:
105 ticket-and-two-replies items, 35 in each of three strata. For each item, read
the ticket and the two replies labelled A and B. The system that produced each
reply is hidden, and the A/B order is randomised and balanced within each stratum.

For each reply, please:
1. rate the procedure as **correct / partially correct / incorrect / cannot judge**;
2. mark whether it contains a **wrong or unsafe step** and whether it **omits a
   required step** (these are independent of the overall rating);
3. choose **A better / B better / equal / both incorrect / cannot judge**. If both
   are wrong, choose "both incorrect" even if one is less wrong.

Judge the procedure, not the writing style or length: would an agent who follows
this reply resolve the ticket the way your team would, without an incorrect or
unsafe step? Use "cannot judge" only when the ticket genuinely does not allow a
decision. The comment box is useful for anything the rubric does not capture.

**Time.** About 1.5 minutes per item; the full set is about two hours including a
short start. There is no need to rush. If you need to stop, just close the browser;
when you return, the app resumes at the next unrated item.

**Blinding.** Please do not try to guess which system produced which reply, and
please do not discuss individual tickets with Alberto until both of you have
finished; independent ratings are part of the result.

**Data.** The tickets are confidential. The app runs on the institute server and
shows anonymised tickets; ratings are stored without ticket text in any external
service. Only aggregate results will appear in the paper.

If anything is unclear or the login does not work, write to me or call
[phone]. Thank you again — this independent check is the part of the revision
that the reviewers asked for most directly.

Best regards,
Domen
